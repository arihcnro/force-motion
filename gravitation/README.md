# แรงดึงดูดระหว่างมวล
สื่อจำลองการเปลี่ยนมวลและระยะของจุดมวลสองก้อน ไม่ใช่การคำนวณวิถีการเคลื่อนที่
ใช้ F = G m1 m2 / r², G = 6.67430e-11 ในหน่วย SI
ปรับมวล 1–100 kg ระยะ 1–10 m ลากมวลขวาเพื่อปรับระยะได้
แรงคู่กิริยา–ปฏิกิริยามีขนาดเท่ากัน ใช้ลูกศรความยาวคงที่เพื่อแสดงทิศ มีคำชี้แจงกำกับ
กราฟแรงกับระยะใช้แกนเชิงเส้นและปรับมาตราส่วนแรงตามมวล มีค่าตัวเลขกำกับ
บันทึกค่าอ้างอิง เปรียบเทียบอัตราส่วน และภารกิจสามกรณี
วิดีโอที่แนบในคำขอนี้เป็นเรื่องคลื่น จึงสร้างตามหัวข้อแรงดึงดูดระหว่างมวลที่ผู้ใช้ระบุ
ตรวจฟิสิกส์ 80 ชุดพารามิเตอร์ รวมการสลับมวล อัตราส่วนแรง ความเร่ง และปฏิเสธระยะศูนย์
ตรวจการลากจริงและภารกิจในเบราว์เซอร์
