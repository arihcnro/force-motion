# การชั่งน้ำหนักในลิฟต์
สร้าง 21 กันยายน 2569 ตามวิดีโอตัวอย่างที่ผู้ใช้แนบ โดยเขียนสื่อใหม่
กำหนดแกนขึ้นบวก g = 9.8 m/s², N = m(g+a), ค่าหน้าปัด kg = N/g
แสดงน้ำหนักจริง แรงแนวฉาก มวลจริง ความเร่ง และค่าหน้าปัดแยกกัน
มวล 20–100 kg, a ระหว่าง −g กับ +g, ความเร็วต้น −5 ถึง +5 m/s
ภาพเคลื่อนไหวคำนวณ v = v0+at และ s = v0t+at²/2 ตลอด 0–2 วินาที ความเร่งคงตัว
เมื่อจบช่วงเวลาเป็นการพักภาพ ไม่ได้สั่งหยุดลิฟต์ทางฟิสิกส์
วัตถุและห้องโดยสารเป็นภาพประกอบ ตำแหน่งวัดที่พื้นลิฟต์เทียบจุดเริ่มต้น
ขอบเขตแบบจำลอง: คนเคลื่อนร่วมลิฟต์ ไม่มีแรงแนวดิ่งอื่น ละเลยแรงต้านอากาศ การสั่น และช่วงเปลี่ยนความเร่ง ไม่จำลองการกระแทก
ตกอย่างเสรีเริ่มคนและลิฟต์ด้วยความเร็วเดียวกัน ได้ N=0 แต่ mg ยังอยู่
ตรวจ 135 ชุดพารามิเตอร์และสถานการณ์จริงในเบราว์เซอร์
