ปริมาณความหมายและความสัมพันธ์
มวล m (kg)สมบัติของคนที่แสดงความเฉื่อย ไม่เปลี่ยนเพราะลิฟต์เร่ง
น้ำหนัก mg (N)แรงโน้มถ่วงที่โลกกระทำต่อคน ชี้ลง เมื่อ m และ g คงที่ น้ำหนักจริงคงที่
แรงแนวฉาก N (N)แรงที่ตาชั่งดันคนขึ้น ค่าเดียวกับขนาดแรงที่คนกดตาชั่ง เรียกน้ำหนักปรากฏเมื่อกล่าวถึงการชั่ง
ความเร่ง a (m/s²)ใช้ค่าแบบมีเครื่องหมายตามแกนขึ้น ความเร่งกำหนดแรงลัพธ์ ไม่ใช่ทิศความเร็วเพียงอย่างเดียว
ค่าหน้าปัดแบบ kgตาชั่งที่สอบเทียบด้วย g = 9.8 แปลงแรงเป็น N/g ค่าในหน่วย kg นี้อาจไม่เท่ามวลจริงเมื่อลิฟต์เร่ง

N กับ mg ไม่ใช่คู่แรงตามกฎข้อที่สาม เพราะกระทำต่อคนเดียวกัน คู่แรงของ N คือแรงที่คนกดตาชั่ง ซึ่งกระทำต่อตาชั่ง

ทำไมทิศการเคลื่อนที่ยังไม่พอ?

ขึ้นและเร็วขึ้น หรือ ลงและช้าลง: a > 0 จึง N > mg
ขึ้นและช้าลง หรือ ลงและเร็วขึ้น: −g < a < 0 จึง N < mg
หยุดนิ่งหรือความเร็วคงตัว: a = 0 จึง N = mg

ตกอย่างเสรี: a = −g จึง N = 0 ตาชั่งอ่านศูนย์ แต่ mg ยังคงมีอยู่ นี่คือภาวะไร้น้ำหนักปรากฏ โดยสมมติว่าคนกับลิฟต์เริ่มด้วยความเร็วเดียวกัน

แบบจำลองละเลยแรงต้านอากาศและการสั่น คนเคลื่อนร่วมกับลิฟต์ และไม่มีแรงแนวดิ่งอื่นบนคน จำกัด a ≥ −g เพื่อไม่ใช้สมมติฐานสัมผัสตาชั่งในกรณีที่ต้องได้ N ติดลบ ไม่จำลองแรงกระแทกจากการเริ่มหรือหยุดความเร่ง

ทดลองและสรุปผล

มวล 60 kg ความเร่งขึ้น 2 m/s² ตาชั่งอ่านเท่าใด?

mg = 588 N และ N = 60(9.8 + 2) = 708 N ค่าหน้าปัดแบบ kg คือ 708/9.8 ≈ 72.24 kg แต่มวลจริงยังคงเป็น 60 kg

เปรียบเทียบ “ขึ้นและช้าลง” กับ “ลงและเร็วขึ้น”

ทั้งสองกรณีมีความเร่งลง ถ้าขนาดความเร่งและมวลเท่ากัน จะอ่านค่าตาชั่งเท่ากัน แม้ความเร็วมีทิศต่างกัน

เมื่อความเร็วผ่านศูนย์ ค่าตาชั่งต้องเท่ากับ mg หรือไม่?

ไม่จำเป็น ความเร็วเป็นศูนย์ขณะหนึ่งยังมีความเร่งได้ หากความเร่งไม่เป็นศูนย์ N จะไม่เท่ากับ mg ทดลองตั้ง v₀ = 2 m/s และ a = −2 m/s² แล้วเลื่อนเวลาไปที่ 1 s
