# สื่อจำลองการแยกองค์ประกอบของแรง

ปรับปรุง 20 กันยายน 2569 ตามแนวทางการทดลองในวิดีโอที่ผู้ใช้แนบ สร้างโค้ด กราฟ และกิจกรรมใหม่

เปิด force-components/index.html ได้โดยตรงโดยไม่ต้องต่ออินเทอร์เน็ต
- ปรับขนาดแรง 0–20 N มุม 0–360° หรือลากปลายลูกศร
- มุมวัดทวนเข็มนาฬิกาจาก +x; F_x = F cos θ, F_y = F sin θ
- ระบุเครื่องหมายองค์ประกอบครบ 4 ควอดแรนต์และกรณีตามแกน
- แรงศูนย์ไม่มีทิศทางแน่นอน
- การหมุนอัตโนมัติเป็นการเปลี่ยนทิศแรง ไม่ใช่แสดงการเคลื่อนที่ของวัตถุ
- มีภารกิจ 3 ภารกิจและแบบฝึก 3 ข้อพร้อมคะแนนและคำอธิบาย
- ไม่บวกแรงเดิมซ้ำกับองค์ประกอบ

เพิ่มทางเข้าใน simulations.html และเพิ่มเนื้อหาเรื่องการแยกแรงในหัวข้อแรงของ lessons.js
ทดสอบสมบัติของเวกเตอร์ 1,805 กรณี ตรวจการลากจริง กรณีแรงศูนย์ มุมตามแนวแกน การหมุน และคะแนนแบบฝึกในเบราว์เซอร์
แบบทดสอบหลัก 10 ข้อ แบบฝึกหัดเดิม และสื่อจำลองก่อนหน้าคงเดิม
