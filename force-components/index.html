ตั้งค่า

ภาพเคลื่อนไหวเปลี่ยนทิศแรงเพื่อสำรวจองค์ประกอบ ไม่ใช่การเคลื่อนที่ของวัตถุ

สมการและความหมาย

Fx=Fcosθ

องค์ประกอบตามแกน x

Fy=Fsinθ

องค์ประกอบตามแกน y

F=Fx2+Fy2

หาขนาดแรงจากองค์ประกอบ

F→=Fxi^+Fyj^

F เป็นขนาดแรง (ไม่ติดลบ) ส่วน Fₓ และ Fᵧ เป็นองค์ประกอบแบบมีเครื่องหมาย โดย î และ ĵ เป็นเวกเตอร์หนึ่งหน่วยตามแกน +x และ +y ตามลำดับ เครื่องหมายลบหมายถึงองค์ประกอบชี้สวนทิศบวกของแกนนั้น

แรงเดิมกับองค์ประกอบทั้งสองเป็นการแทนแรงเดียวกัน ห้ามนับรวมเป็นแรง 3 แรง เมื่อ F = 0 เวกเตอร์ไม่มีทิศทางแน่นอน มุมที่ตั้งไว้ใช้กำหนดทิศเมื่อเพิ่มขนาดแรงอีกครั้ง

ภารกิจสำรวจ

ตั้ง F = 10 N และ θ = 30° แล้วเปรียบเทียบขนาด Fₓ กับ Fᵧ

แนวทางสรุปผล

ที่ 30° ได้ Fₓ ≈ 8.66 N และ Fᵧ = 5.00 N ส่วนที่ 150° ได้ Fₓ ≈ −8.66 N และ Fᵧ = 5.00 N แสดงว่าการเปลี่ยนทิศอาจเปลี่ยนเครื่องหมายโดยขนาดองค์ประกอบเท่าเดิม ที่ 90° ได้ Fₓ = 0 และ Fᵧ = 10 N
