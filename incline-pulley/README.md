# รอกกับพื้นเอียง
ระบบสองมวล เริ่มจากหยุดนิ่ง เชือกตึงไม่ยืด รอกและเชือกไม่มีมวล รอกไม่มีความเสียดทาน
กำหนดบวก: m1 ขึ้นพื้น m2 ลง คำนวณ D=m2g-m1g sinθ และ N=m1g cosθ
ถ้า |D|≤μsN ระบบรักษาสมดุลได้ f=-D, a=0, T=m2g
ถ้าเกินขีดจำกัด f=-sign(D)μkN, a=(D+f)/(m1+m2), T=m2(g-a)
จำกัด 0≤μk≤μs และปรับค่าให้สัมพันธ์กัน
เมื่อเปลี่ยนตัวแปรจะเริ่มจากหยุดนิ่งใหม่ จึงไม่จำลองการเปลี่ยนสภาวะระหว่างกำลังไถล
ภาพใช้ q=at²/2 v=at ระยะบนพื้นเท่ากับระยะมวลแขวน เชือกมีความยาวคงที่
หยุดแสดงเมื่อ |q|=1 m หรือ t=10 s เป็นการพักภาพไม่ใช่การชนหรือหยุดทางฟิสิกส์
ตรวจสมการแยกมวล 324 กรณี และตรวจตัวอย่าง/ภาพในเบราว์เซอร์
