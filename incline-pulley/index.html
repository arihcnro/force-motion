แรงบนวัตถุแต่ละก้อน

ลูกศรแสดงทิศ ไม่ใช่มาตราส่วนขนาดแรง แสดงแรงจริง ไม่วาดองค์ประกอบน้ำหนักซ้ำเป็นแรงเพิ่ม

วิเคราะห์ระบบก่อนเริ่มเคลื่อนที่

กำหนด D = m₂g − m₁g sin θ เป็นผลต่างของแรงโน้มถ่วงตามแนวการเคลื่อนที่ แรงปฏิกิริยาตั้งฉากบนมวลแรกมีขนาด N = m₁g cos θ เพราะเชือกขนานพื้นเอียง

|D|≤μsN

ถ้าเงื่อนไขนี้เป็นจริง ระบบที่เริ่มหยุดนิ่งรักษาสมดุลได้: a = 0, T = m₂g และองค์ประกอบแรงเสียดทานตามแกนขึ้นพื้นคือ f = −D โดย |f| ไม่เกิน μₛN ที่ขีดจำกัดยังเป็นสมดุลจำกัด ไม่บังคับให้ไถลเอง

ถ้า |D| > μₛN ระบบเริ่มเลื่อน: D > 0 ทำให้ m₁ ขึ้นพื้นและแรงเสียดทานจลน์ลงพื้น ส่วน D < 0 ทำให้ m₁ ลงพื้นและแรงเสียดทานจลน์ขึ้นพื้น ขนาดแรงเสียดทานจลน์เท่ากับ μₖN

ภารกิจสำรวจและสรุปผล

แรงเสียดทานชี้ขึ้นพื้นเสมอหรือไม่?

ไม่เสมอ แรงเสียดทานต้านการเลื่อนสัมพัทธ์หรือแนวโน้มการเลื่อน ถ้ามวลแขวนดึงมวลบนพื้นให้ขึ้น แรงเสียดทานบนมวลนั้นจะชี้ลงพื้น ลองเปลี่ยนมวลแขวนเพื่อเปรียบเทียบ

แรงตึงเชือกเท่ากับน้ำหนักมวลแขวนเสมอหรือไม่?

เท่ากันเมื่อความเร่งเป็นศูนย์ หากมวลแขวนเร่งลง จะได้ T < m₂g หากเร่งขึ้น จะได้ T > m₂g

ทดลองพื้นลื่น: m₁ = 3 kg, m₂ = 5 kg, θ = 30°

D = 49 − 14.7 = 34.3 N, a = 34.3/8 = 4.2875 m/s² และ T = 5(9.8 − 4.2875) = 27.5625 N มวลบนพื้นขึ้นและมวลแขวนลง
