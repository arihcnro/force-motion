กำหนดตัวแปร

ปรับค่าได้ระหว่างทดลอง การเปลี่ยนมวลจะเริ่มการทดลองใหม่

แบบจำลองนี้กำหนด 0 ≤ μₖ ≤ μₛ ≤ 1 และ g = 9.8 m/s²

ลองสถานการณ์

เลือกสถานการณ์แล้วกดเริ่มการทดลอง

วิเคราะห์แรง ณ ขณะนี้

Fx = ±F cos θ
Fy = F sin θ
ΣFx = Fx + fx = max
ΣFy = Fy + N − mg = may

ขณะสัมผัสพื้นและไม่มีความเร่งแนวดิ่ง: N = mg − Fy ≥ 0

ยังไม่ไถล: |fs| ≤ μsN
ขณะไถล: |fk| = μkN และมีทิศตรงข้ามกับ vx

เมื่อยกพ้นพื้น: N = 0 และ f = 0

ภารกิจสำรวจ

  1. ตั้ง m = 2 kg, θ = 0°, μₛ = 0.50 ค่อย ๆ เพิ่มแรงจากศูนย์ กล่องเริ่มไถลเมื่อแรงมากกว่าเท่าใด?
  2. เทียบแรงดึง 8 N กับ 12 N เมื่อกล่องเริ่มจากหยุดนิ่ง แรงเสียดทานมีชนิดและขนาดต่างกันอย่างไร?
  3. ตั้ง F = 12 N แล้วเปลี่ยนมุมจาก 0° เป็น 30° สังเกตทั้งแรงดึงแนวราบและแรงปฏิกิริยาตั้งฉาก ก่อนเปรียบเทียบความเร่ง
  4. ขณะกล่องไถล ให้ลดแรงดึงเป็นศูนย์ กล่องหยุดอย่างไร? เมื่อหยุดแล้วแรงเสียดทานเป็นเท่าใด?
แนวทางตรวจคำตอบ

ที่มุม 0° แรงเสียดทานสถิตสูงสุดเป็น 9.8 N; F = 8 N ให้ fₛ = 8 N จึงอยู่นิ่ง ส่วน F = 12 N ทำให้ไถล โดย fₖ = 5.88 N และ aₓ = 3.06 m/s²

ที่ F = 12 N, θ = 30° ได้ Fₓ ≈ 10.39 N, N = 13.60 N, fₖ = 4.08 N และ aₓ ≈ 3.16 m/s² หลังเริ่มไถล หากลดแรงดึงเป็นศูนย์ แรงเสียดทานจลน์จะชะลอกล่องจนหยุด แล้วแรงเสียดทานเป็นศูนย์เมื่อไม่มีแรงแนวราบอื่น

สมมติฐานของแบบจำลอง

วัตถุเป็นอนุภาคเพื่อวิเคราะห์การเลื่อนที่ ไม่พิจารณาการหมุนหรือการพลิกคว่ำ พื้นราบแข็งเกร็งอยู่นิ่ง แรงดึงมีขนาดและมุมตามค่าที่กำหนด ไม่มีแรงต้านอากาศ ใช้แบบจำลองแรงเสียดทานแห้ง และให้ g คงตัว

หากแรงดึงแนวดิ่งมากกว่าน้ำหนัก วัตถุจะยกพ้นพื้นและเคลื่อนที่ในสองมิติ เมื่อกลับถึงพื้นให้การชนในแนวตั้งฉากเป็นแบบไม่กระดอน โดยไม่คิดอิมพัลส์เสียดทานแนวราบขณะชน จากนั้นคำนวณแรงเสียดทานขณะสัมผัสพื้นตามปกติ ค่าแรงและความเร่งที่แสดงไม่รวมแรงกระแทกชั่วขณะ

กราฟเริ่มใหม่เมื่อเปลี่ยนมวลหรือเริ่มการทดลองใหม่ ตำแหน่ง x และ h อ้างอิงจากจุดเริ่มต้นและความสูงใต้กล่องเหนือพื้นตามลำดับ
